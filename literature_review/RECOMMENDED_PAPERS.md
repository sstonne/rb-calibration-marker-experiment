# S급 — 없으면 리뷰어가 반드시 묻는다

## 1위 · R2. Allegro, Multi-Camera Hand-Eye (RA-L 2024)

📄 https://arxiv.org/html/2406.11392 · [코드](https://github.com/davidea97/Multi-Camera-Hand-Eye-Calibration) (저장소에 사본 있음)

**결과 — GT translation** (⚠️ 카메라 **원점** 위치 오차)

| 데이터 | 오차 |
|---|---:|
| small / D455 | **13.21 mm** |
| small / L515 | 13.68 mm |
| large | 19~45 mm |

원문 식 (8) $e_t^{GT}=\frac{1}{N}\sum\lVert t-\hat{t}\rVert_2$ — 카메라별 원점 오차의 평균.
회전은 0.07°로 매우 작은데 이동만 13 mm → 오차가 **광축 방향**에 몰려 있다는 신호.
**산업 실험은 10장 미만 / 15장**으로 보정.

**센서 —** Kinect V2 / **RealSense D455** / **L515** ×4 (전부 고정). 산업셀 ABB 4대 · KUKA 3대
**RealSense 대비 —** D455·L515는 **1배** (같은 계열)

**왜 1위 —**
- **결합(joint optimization)을 가진 유일한 경쟁자**다. 나머지 baseline은 카메라를 따로 풀고 조립한다.
- **RealSense + 로봇 + 멀티캠**을 모두 만족하는 유일한 방법 논문이다.
- **코드가 공개**돼 우리 데이터로 **직접 돌릴 수 있다.**
- **eye-in-hand 모드(`calibration_setup: 0`)도 지원**한다 → **고정캠·그리퍼캠 둘 다** 돌려야 한다.
- FK를 100 % 신뢰한다 → 우리 soft anchor와의 차이가 깨끗이 드러난다.

## 2위 · R3. Zhou, Multi Hand-Eye Graph (IEEE TIE 2024)

📄 https://arxiv.org/pdf/2305.02518

**결과 —** 폐루프 오차 **0.6274 / 0.6345 / 0.6938 mm**. Wu 대비 **일부 loop만** 개선(나머지는 Wu가 0.4213 / 0.5812 mm로 더 낮음).
⚠️ **참값을 못 재서 폐루프로 대신한 값이다.** 작다고 정확한 게 아니다.

**센서 — Hikvision MV-CE060-10UC ×5** (6 MP RGB) = **손목 3 + 고정 2**. 로봇 UR5 ×2 + UR3

**RealSense 대비**

| | |
|---|---|
| 가격 | **≈ 1~1.3배** (대당 20~40만 원, 단종. 정식 견적 `미확인`) |
| 성능 | 화소 **선형 2.4배** (3072×2048). 깊이 없음 |

**왜 2위 —**
- **고정캠과 손목캠을 한 최적화로 푸는 유일한 선행연구**다. 우리가 서 있는 계보에 우리 말고 이것뿐이다.
- 코드 공개가 확인되지 않아 baseline으로 돌릴 수는 없다. 대신 **기여를 정의할 때 이 논문 대비로 잡아야 한다** — "R3는 참값 없이 폐루프로만 평가했다. 우리는 독립 GT로 잰다."
- **센서 업그레이드 경로**이기도 하다 — 비슷한 값에 선형 2.4배. (단 우리가 1920×1080으로 먼저 올리면 격차는 1.6배로 준다.)

## 3위 · C1. FusedBA (Sensors 2024)

📄 https://www.mdpi.com/1424-8220/24/23/7416 · [데이터·프로젝트](https://koonyook.github.io/MCalib/)

**결과 — 보정에 안 쓴 별도 2분 기록의 3D 점 오차** (mocap GT, 33회 반복)

| 방법 | 독립 3D 오차 | 학습 재투영 |
|---|---:|---:|
| Anipose | 10.06 mm | — |
| BAp15 | 2.33 mm | **0.231 px** |
| **FusedBA** | **2.14 mm** | 0.260 px |
| MocapAssisted | 1.36 mm | — |

> 🔑 **학습 재투영이 더 낮은 BAp15가 독립 3D는 더 나빴다.**
> **"작은 px가 좋은 mm를 보장하지 않는다"**는 우리 주장의 외부 근거다.

**센서 —** 보정: **e-con See3CAM_24CUG ×7** (1920×1200 글로벌셔터). GT: **Qualisys Arqus A12 ×10 + Miqus M3 ×6**. 로봇 ❌

**RealSense 대비**

| | |
|---|---|
| 가격 (카메라) | **≈ 1배** — 대당 20~30만 원 |
| 가격 (GT 장비) | **30배 이상/대** — 억대 시스템 |
| 성능 | 화소 **선형 1.5배**. **글로벌셔터**. 깊이 없음 |

**왜 3위 —**
- **평가 논리가 우리 held-out과 같은 유일한 논문**이다. "보정 → 별도 기록 → 독립 GT 대비 3D 오차"를 그대로 가져오면 외부 GT 평가를 선행연구로 방어할 수 있다.
- 카메라 가격대가 우리와 같다.
- ⚠️ 볼륨이 수 m라 탁상(0.43~0.89 m)인 우리와 **거리 조건이 다르다.** 우리 거리에서는 바닥이 더 낮아야 정상이다.

# A급 — 핵심 근거로 인용

## 4위 · C5. Laven, Imperfect 3-D Targets (IEEE TIM 2026)

📄 https://ieeexplore.ieee.org/document/11408373/ · 원문 [`Related_work/`](../Related_work/)

**결과 — 리그 3개** (Table I·II·IV)

| | 리그 0 | 리그 1 | 리그 2 |
|---|---|---|---|
| 용도 | 인체 | 피부 표면 | 장기 |
| 카메라 | **20 MP × 24** | **5 MP × 5** | **5 MP × 12** |
| 타깃 | 400 mm PMMA 큐브 | 50 mm 알루미늄 큐브 + 종이 | **30 mm 3D 프린트 큐브 + 종이** |
| 카메라당 이미지 | 119 | 48 | 77 |
| 재투영 (기존 → 제안) | 0.91 → **0.59 px** | 4.30 → **1.34 px** | 5.85 → **0.61 px** |
| **타깃 형상 보정량** | 평균 **0.3 mm** | **15 µm rms** | 평균 **0.37 mm** |

| 고정점(gauge) 선택 | 스케일 오차 (리그 0 / 1 / 2) |
|---|---|
| 좋은 고정점 | 0.1 % / 0.5 % / 0.9 % |
| **나쁜 고정점** | 0.2 % / **−3.1 %** / **−5.0 %** |

**센서 —** 20 MP·5 MP (제조사 미기재). **리그 0만 UR3e**(±30 µm)로 구형 타깃을 30곳에 옮겨 검증
**RealSense 대비 —** 화소 선형 **2.4~5배**. 가격 `미확인`

**왜 4위 — 우리 시스템에 직접 걸리는 게 네 개다.**
1. **리그 2가 우리 큐브와 가장 닮았다.** 3D 프린트 큐브 + 종이 마커 → 형상 오차 **0.37 mm.**
   → 우리 큐브의 **면별 형상 보정이 필요하다는 외부 근거.**
2. **나쁜 고정점이 스케일을 −3~−5 % 틀었다.**
   → 스케일 문제의 원인 후보가 intrinsic 외에 **형상 보정의 gauge 선택**도 있다.
3. **인쇄 정밀도 ±50 µm** = 51 mm 마커의 **0.1 %**.
   → 인쇄 정밀도로는 1 % 차이가 안 나온다. **스케일 1.0 복원과 일관.**
4. **리그 0은 로봇으로 옮긴 타깃을 "강체 변환까지 맞춘 뒤" 비교했다.**
   → 우리 [상대 측정 실험 A](../RELATIVE_MEASUREMENT_EXPERIMENTS.md)의 **직접 선행 사례.**

## 5위 · R5. Ulrich & Hillemann, Uncertainty-Aware Hand–Eye (T-RO 2024)

📄 https://publikationen.bibliothek.kit.edu/1000167305

**결과 —** UR3e에서 RRMSE **0.193 px**, RAE **0.00073 mm²**. **25 자세**
⚠️ **RAE는 mm²**(평균 제곱 재구성 오차)다. mm로 읽으면 안 된다.
⚠️ 0.193 px는 **보정된 로봇 pose로 평가한 값**이다. raw FK를 고정한 우리 평가와 같지 않다.

**센서 — IDS U3-3280SE** (2448×2048) + 8 mm 렌즈 별도. 로봇 UR3e

**RealSense 대비**

| | |
|---|---|
| 가격 | **≈ 3~5배** (본체 + 렌즈. 정식 견적 `미확인`) |
| 성능 | 화소 **선형 1.9배**. 산업 계측 등급 렌즈. 깊이 없음 |

**왜 5위 —**
- 로봇 pose의 **반복정밀도와 절대정확도를 따로** 확률 모델링한다. **우리 soft anchor와 가장 가까운 경쟁 개념**이라 본문에 별도 문단이 필요하다.
- 0.193 px는 **이 센서 품질이 전제**다. 우리 px와 직접 비교하면 안 되는 이유로도 인용한다.

## 8위 · R4. Ha, Probabilistic AX=YB (T-RO 2023)

|---|---|
| 가격 | **≈ 0.25배** (약 10만 원 미만, 대략값) |
| 성능 | 화소는 RealSense 상한과 같다. 깊이 없음. 소비자용 렌즈 |

**왜 8위 —**
- 측정마다 **공분산을 주는 확률적 AX=YB**다. FK를 불확실하게 다루는 발상의 **이론적 선행**이다. (R5가 더 직접적이라 한 단계 아래.)
- **웹캠으로 T-RO에 실렸다.** 센서 가격이 게재를 막지 않는다는 근거다.
- **반면교사다.** 결과 0.50 mm가 **GT 자체 오차(약 1 mm)보다 작다.** 그래서 절대값은 약하고 **비교군과의 차이(4.33 mm)만 유효**하다. 저자도 상대 비교로 주장한다. **"GT는 주장보다 훨씬 정확해야 한다"**의 실제 사례.

## 9위 · C8. AIRLS (Photonics 2024)

📄 https://www.mdpi.com/2304-6732/11/9/867

**결과 — 보정과 다른 검증 wand**로 5회씩

| wand | 오차 |
|---|---:|
| 390 mm | **0.42 ± 0.09 mm** |
| 500 mm | **0.46 ± 0.13 mm** |

**센서 — OptiTrack FLEX13 ×4** (IR mocap, 1280×1024 @ 120 Hz, 약 2 m). 약 1,000 frame. 로봇 ❌

| | |
|---|---|
| 가격 | ✅ **대당 $1.5K = 6~7배**. 시스템 10~20배 |
| 성능 | sub-mm. 단 **반사 마커만 본다 — 일반 물체를 못 본다** |

**왜 9위 —** **보정 데이터와 평가 데이터를 분리한다**는 원칙의 깔끔한 실물 사례다.
⚠️ 두 마커 사이 거리라 공통 편향을 못 잡는다. **우리가 왜 거리가 아니라 위치로 평가해야 하는지**의 대조군으로도 쓴다.

# 가격 대비 성능 한눈에

| 배수 | 논문 | 센서 | 성능 요지 |
|---:|---|---|---|
| **0.25배** | **R4** | Logitech C920 | 화소는 RealSense 상한과 같음. 그래도 T-RO |
| **1배** | **R2, R8, R7, R11** | **RealSense 그대로** | 우리와 동일 조건 |
| ~1배 | C1 | e-con See3CAM | 선형 1.5배 + 글로벌셔터 |
| **1~1.3배** | **R3** | **Hikvision 6 MP** | **선형 2.4배 ← 최고 가성비** |
| 1.5~2배 | R9, D1 | Azure Kinect / D455 | 깊이 개선. **color는 그대로거나 낮음** |
| 3~5배 | R5 | IDS 5 MP | 선형 1.9배 + 계측 렌즈 |

| 30배+ | C1의 GT | Qualisys | GT 전용 |
| 300배+ | C9 | CMM | 다른 세계 |

## 결론 3가지

1. **0~5 mm를 보고한 로봇 포함 논문은 전부 RealSense 1대짜리다**(R8·R7·R11). **센서가 우리 발목을 잡는다는 증거가 없다.** 게다가 **웹캠(R4)으로도 T-RO에 실렸다.**
2. **업그레이드는 R3 노선이다**(비슷한 값에 선형 2.4배). D455는 color가 오히려 낮아 무의미하다. 그리고 **1920×1080으로 먼저 올리면 공짜로 선형 1.5배**다.
3. **sub-mm 논문은 전부 6~300배 장비다.** 같은 표에 넣으려면 **센서 열을 반드시 함께** 넣는다.

# 제외한 논문

**결과를 원문에서 확인하지 못했거나, 확인해 보니 검증이 순환이거나 지표가 달랐던 논문**이다. 본문에서 수치를 인용하지 않는다.

| 논문 | 제외 이유 | 인용해도 되는 범위 |
|---|---|---|
| **N1** Marker-Based Multi-Camera (arXiv 2505.02539) | **GT가 자기 최적 결과다** — 원문: *"the optimized calibration that obtained the best results ... was taken as ground truth."* 0.0012 mm는 기준 카메라와의 **평면 정렬 잔차**. 비교 방법 없음. 작업 거리 미기재 | 관련 연구에서 "RealSense + 큐브 마커를 쓴 선례" **한 줄만**. 수치 인용 금지 |
| **R15** GWM-View (RCIM 2023) | "1 mm 미만"이 **특징점 두 개 사이 거리**다. 물체 위치 오차가 아니다. 수치는 그래프로만 제시 | 멀티캠 + 산업 로봇 구성의 선례 |
| **C4** Weighted AprilTag PnP (Algorithms 2026) | "20카메라"가 **GoPro 1대를 20위치로 옮긴 것**이다. 실데이터 GT 없음 | AprilTag 초기화 기법 참고 |
| **C2** 비동기 wand (Sensors 2024) | 640×480 IR 카메라, 비행체 위치추정 용도. 우리와 관련성 낮음 | — |

세부 근거는 [`SENSOR_TOPOLOGY_MATRIX.md` §9](SENSOR_TOPOLOGY_MATRIX.md).
