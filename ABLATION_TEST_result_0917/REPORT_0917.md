## 촬영 세션 설명

| 세션 | 무엇을 하나 | 어디에 쓰나 |
|---|---|---|
| **session1** (핸드헬드) | 로봇이 큐브를 **쥔 채** 공중에서 16가지 자세를 취하고, 고정캠 3대가 큐브를 찍는다. 큐브는 그리퍼에 고정돼 있으므로 로봇 FK로 큐브 위치를 예측할 수 있다. | 플랜지→큐브 변환 **T_flange_cube(FtC)** 를 구한다. 고정캠 위치의 초기값도 여기서 나온다. |

| **session3** (손목 모션) | 큐브는 마지막 자리에 둔 채, 로봇이 **손목만** 15가지로 돌리며 그리퍼캠으로 바닥 ChArUco 보드를 찍는다. | 그리퍼캠의 손–눈 변환 **T_gripper_cam** 을 구한다(움직이는 카메라가 정지 보드를 보는 표준 eye-in-hand). 정지해 있는 큐브도 같이 찍히므로 추가 관측으로 쓴다. |

세 세션 모두 매 사진마다 로봇 FK(관절값→플랜지 위치)를 함께 저장한다.

## 용어

| 용어 | 뜻 |
|---|---|
| held-out | session2의 15개 놓는 위치(placement) 중 1개를 학습에서 빼고 나머지로 캘리브레이션한 뒤, 뺀 위치에서 잰 오차. 15번 반복(LOPO)해 합침 |
| Cube RMSE (px) | 큐브 코너를 이미지에 재투영했을 때 검출 코너와의 차이. `sqrt(mean(dx²+dy²))` |
| joint 위치 mm | 고정캠 3대 코너를 한꺼번에 묶어 삼각측량한 큐브 위치 vs FK@T_flange_cube 정답. **정확도 기준 지표** |
| 카메라 합의 mm | 고정캠 각 1대씩 따로 구한 큐브 위치끼리의 차이(pairwise). 단일 카메라 깊이 노이즈가 그대로 들어감 |
| T_flange_cube (FtC) | 플랜지→큐브 원점 변환. session1(공중 16포즈)로 비전 적합. A3/B1의 "FtC FK" |
| A3 | FtC FK fixed: session1 T_flange_cube × 로봇 FK로 큐브 위치를 고정하고 카메라만 최적화 |

## 1. Table 1 — 방법 비교 (A1~B1)

### 1.1 방법별 전체 지표 (1920×1080, held-out 15-fold)

| Row | 학습 표적 | 최적화 | FK 처리 | train px | held-out px | cross-view held-out px | joint mm 평균 / 중앙값 / P95 | joint 축별 \|dx\| / \|dy\| / \|dz\| mm | joint ° | 카메라 합의 mm |
|---|---|---|---|---:|---:|---|---|---|---:|---:|
| A1 | board+cube | Sequential | VISION | 2.83 | 2.85 | 5.53 | 1.29 / 1.26 / 1.82 | 0.88 / 0.43 / 0.75 | 0.26 | 2.80 |
| A2 | board+cube | Unified | VISION | 2.62 | 2.62 | 5.77 | 1.22 / 1.17 / 1.72 | 0.80 / 0.41 / 0.72 | 0.24 | 3.11 |
| **A3** | board+cube | Unified | **FtC FK fixed** | **1.62** | **1.77** | 4.90 | **0.62 / 0.56 / 1.13** | 0.25 / 0.48 / 0.10 | 0.24 | 2.32 |
| B1 | cube | Unified | FtC FK fixed | 1.62 | 1.79 | 5.27 | 0.65 / 0.60 / 1.06 | 0.25 / 0.51 / 0.11 | 0.27 | 2.64 |

- **train / held-out px**: 학습 데이터 vs 학습에서 뺀 placement의 큐브 재투영 RMSE. 둘이 같으면 과적합 없음.
- **cross-view px**: 카메라 A의 PnP 포즈를 캘리브레이션으로 B에 옮겨 B의 검출 코너와 비교(모든 카메라 쌍). 카메라 간 일관성 검증.
- **joint mm / °**: 고정캠 3대 공동 삼각측량 위치 vs FK@T_flange_cube, **held-out placement에서** 잰 값(모든 열이 held-out). **정확도 기준 지표.** P95 = 상위 5% 최악값.
- **joint 축별 mm**: 같은 오차를 로봇 base 좌표 x / y / z 축으로 나눈 절대값 평균. VISION 행(A1, A2)은 x·z에 +0.7~0.9mm의 일정한 편향(부호 평균 +0.80 / +0.72)이 있고, FtC FK fixed 행은 x·z 편향이 사라지는 대신 y에 −0.35~−0.42mm 편향이 남음 — 4.1의 파지 y 흔들림(닫힘 방향)과 같은 축.
- **카메라 합의 mm**: 카메라 한 대씩 따로 구한 held-out 큐브 위치끼리의 pairwise 차이. 외부파라미터 일관성.
- **FtC FK** : session1 비전으로 잰 flange-to-cube 변환 × 로봇 FK. fixed = 큐브 위치를 이 값으로 고정하고 카메라만 최적화.

### 1.2 결론
- **FtC FK fixed 행(A3, B1)이 VISION 행(A1, A2)의 절반 오차** (1920: 0.62~0.65 vs 1.22~1.29mm). 세 해상도 모두 같은 결과.
- FK를 고정하면 보드 유무(A3 vs B1)의 차이는 0.03mm 이내. 이유: 고정캠과 그리퍼캠을 잇는 공유 변수가 큐브 위치뿐인데, FtC FK fixed는 그것을 FK로 고정해 변수에서 빼므로 두 그룹이 독립이 됨 → 보드·그리퍼캠 쪽 정보가 고정캠 결과에 영향을 줄 수 없음. 같은 이유로 FK 고정 + Sequential 행은 A3와 동일해져 표에서 제외.
- 통합의 효과는 큐브 위치가 자유 변수일 때 나타남: A1(순차) 1.29 vs A2(통합) 1.22mm, 완전 독립(두 그룹이 아무것도 공유하지 않음, `fit_calibration_methods.py` 독립_no-fk) 1.55 vs 통합_no-fk 1.10mm.
- **추가 예정 (데이터 보강 후 재평가):**
  - 보드만 사용하는 방식(A0/B3): 지금은 보드가 정지해 있어 고정캠이 보드를 한 자세로만 보므로 앵커가 부족함. 보드를 옮겨 가며 촬영하는 방식으로 재촬영 후 추가.
  - FK-corrected 방식(FtC FK soft factor 등 FK 보정 계열): 데이터 추가 후 함께 평가.

## 3. 정확도 검증 (외부 GT 없이)

### 3.1 session1 / session2 joint 상대 검증 (1920, A3 T_base_Ci)

두 포즈 i→j의 큐브 이동을 로봇 FK로 예측한 것과 고정캠 3대 joint로 관측한 것을 비교(모든 쌍, 양방향). 카메라·FK의 공통 편향이 상쇄되고, T_flange_cube·FK·카메라 위치가 일관된지 본다.

| 세션 | 상대 mm (평균/중앙/P95) | 상대 ° | 상대 px |
|---|---|---:|---:|
| session1 handheld (16포즈, 120쌍) | 1.31 / 1.25 / 2.50 | 0.45 | 3.10 |
| session2 held (15포즈, 105쌍) | 1.04 / 0.73 / 3.23 | 0.37 | 2.98 |

- 상대 오차(1.0~1.3mm)가 held-out 오차(0.65mm)보다 약 1.4배 큰 것은 두 포즈의 오차가 합쳐지기 때문(각각 e면 합성은 √2·e). 새로운 오차가 생긴 게 아님.
- 멀리(최대 370mm)·많이(최대 120°) 움직인 쌍이라고 오차가 더 크지 않음 → FK나 T_flange_cube에 거리·각도에 비례해 커지는 오차(스케일 오차, 축 기울어짐 등)는 없음.
- 같은 상대 검증을 카메라 한 대의 PnP만으로 하면 6.0px, 3대를 묶은 joint로 하면 3.0px → 3대 묶음 최적화가 오차를 2배 줄임.

## 4. T_flange_cube (플랜지→큐브) 반복성

### 4.1 session1 재파지 4회 (1920)

| 촬영 | x | y | z (mm) | 기울기 | fit RMSE |
|---|---:|---:|---:|---:|---:|
| 0917a | −0.09 | −0.30 | 160.82 | 2.03° | 1.07px |
| 0917b | −0.01 | 0.42 | 160.97 | 2.10° | 1.05px |
| 0917c | −0.03 | 0.48 | 160.97 | 2.07° | 1.08px |
| 0917d | −0.06 | −0.20 | 160.88 | 2.10° | 1.05px |
| *4회 std (흩어짐)* | 0.03 | 0.39 | 0.06 | 0.03° | |

도면 nominal: (0, 0, 160.0) + Ry(180°). 위 4행은 촬영별 값, 마지막 행은 그 흩어짐(표준편차).

- **x, z(파지 깊이), 기울기는 4회 모두 0.1mm / 0.03° 안에서 같음** → 재파지해도 재현됨.
- **y(손가락 닫힘 방향)만 ±0.4mm 흔들림.** 값이 −0.3·−0.2와 +0.42·+0.48 두 무리로 갈림 → 그리퍼가 닫힐 때 어느 손가락이 먼저 닿느냐에 따라 파지 중심이 두 상태 중 하나로 정해지는 것으로 보임(백래시/유격). 4회로는 확정 못 하며, 재파지 10회 이상으로 확인 필요.
- 이 y 이동이 카메라 오차가 아님을 확인: 카메라 3대를 따로 써서 구해도 세 대 모두 b/c에서 y가 + 방향으로 0.6~1.2mm 움직임. 서로 다른 방향의 세 카메라가 같이 움직였으므로 큐브가 실제로 그 위치에 물린 것.
- session2에서 큐브를 15번 다시 집었을 때의 흩어짐은 y 0.17 / z 0.11mm(std)로 같은 범위.

## 5. 슬립 (session2 전·중·후)

held(놓기 직전, 그 위치의 첫 사진) 기준으로 released(그리퍼 연 후)·picked(다시 집은 후)의 큐브 이동.
- **px**: 같은 카메라 코너 픽셀 이동(외부파라미터·FK 불사용), 고정캠 3대 평균.
- **mm/°**: 고정캠 3대 코너를 한꺼번에 6-DoF 적합(row A3의 T_base_Ci)한 joint 포즈 차이 — 카메라 한 대의 깊이 노이즈가 상쇄된 값. `eval_slip_joint.py`.

| 해상도 | 구간 | 코너 이동 px (평균/중앙/P95) | joint 위치 mm (평균/중앙/P95/최대) | joint 회전 ° |
|---|---|---|---|---:|
| 1920×1080 | 전→중(열기) | 0.32 / 0.22 / 0.74 | 0.12 / 0.08 / 0.31 / 0.41 | 0.07 |
| | 전→후(재파지) | 0.35 / 0.25 / 0.80 | 0.13 / 0.09 / 0.33 / 0.42 | 0.06 |
| 1280×720 | 전→중 | 0.26 / 0.16 / 0.49 | 0.13 / 0.08 / 0.33 / 0.45 | 0.15 |
| | 전→후 | 0.24 / 0.15 / 0.58 | 0.13 / 0.09 / 0.37 / 0.48 | 0.10 |
| 848×480 (11세트) | 전→중 | 0.14 / 0.10 / 0.41 | 0.15 / 0.11 / 0.31 / 0.35 | 0.16 |
| | 전→후 | 0.13 / 0.08 / 0.40 | 0.14 / 0.10 / 0.31 / 0.31 | 0.18 |

- **열기·재파지 슬립: 중앙값 0.1mm, P95 0.3mm, 최대 0.5mm.** 세 해상도가 같은 값 → 측정 노이즈가 아니라 실제 이동.
- px 이동은 해상도에 비례해 줄어들고 검출 노이즈 바닥(0.3~0.5px @1920) 안.
- joint 적합 잔차(held) 0.40~0.84px → 3대가 같은 강체를 보고 있음(한 카메라만 튀는 경우 없음).
- 최대치(0.4~0.5mm)는 set 10 등 실제로 밀린 세트. set 10은 세 방법(코너 재검출, ECC 정합, 조명불변 ECC)이 동일한 1.9px을 내고, 바닥 보드 기준 카메라 이동은 0.01px → 카메라 흔들림이 아닌 큐브 이동.
- 측정 정밀도 자체(합성 시프트 복원 오차)는 코너 재검출·ECC 모두 0.02~0.07px로 이미 바닥. 더 줄이려면 상태당 여러 장 촬영 평균(√N) 또는 열기 속도/놓는 높이 조정으로 실제 이동을 줄여야 함.
