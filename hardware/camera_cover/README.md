# RealSense D435 그리퍼 커버 (Robotiq 2F-85 / 2F-140)

커버 형상은 추정값이 아니라 **Intel 공식 메시에서 직접 뽑은 실제 D435 외형**을 씁니다.

```bash
python d435_gripper_cover.py            # 이 디렉터리에 STL 생성
python d435_gripper_cover.py /tmp/out   # 다른 데 저장
```

| 파일 | 용도 | 대략 출력 시간 |
|---|---|---|
| `d435_gauge.stl` | **먼저 이것부터.** 끼움을 확인하는 시험 조각 (36 mm) | 20분 |
| `d435_sleeve.stl` | 카메라를 감싸는 커버 본체 | 2시간 |
| `d435_arm.stl` | 툴 플랜지에 끼우는 암 (**선택**, 아래 4단계 참고) | 3시간 |

## 형상 출처

`d435_profile.json` 은 `extract_profile.py` 가 아래 메시에서 뽑은 것입니다.

```
realsenseai/realsense-ros : realsense2_description/meshes/d435.dae
```

CAD 에서 나온 메시라 나사 구멍까지 들어 있습니다. 여기서 읽은 값:

| 항목 | 값 |
|---|---|
| 바디 | 89.91 × 25.00 × 25.05 mm |
| 뒷면 M3 (Ø2.5 탭) | x = ±22.5 → **간격 45.0 mm**, 높이 정중앙 (바닥에서 12.5 mm) |
| 바닥 1/4-20 (Ø6.35) | x = 0, 앞면에서 14.9 mm 뒤 |
| 앞면(렌즈면) 외곽 | 84.5 × 19.5 mm |

## 형상에서 중요한 두 가지

**1. 단면이 스타디움(알약) 모양입니다.** 양 끝이 반경 12.5 mm 반원입니다. 90 × 25
사각형이 아닙니다. 캐비티는 이 실루엣을 `CLR` 만큼 바깥으로 오프셋해서 만듭니다.

**2. 깊이 방향으로 배가 부릅니다.** 앞면에서 약 17 mm 지점이 가장 넓고(89.9 × 25.0),
앞면(84.5 × 19.5)과 뒷면(약 78 × 19)은 그보다 작습니다. 그래서 앞에서 밀어 넣는 한
덩어리 커버는 원리상 **가장 넓은 벨트에서만** 카메라에 밀착됩니다. 그 벨트가 좌우·상하를
잡고, 뒷면 M3 나사 2개가 앞뒤를 잡습니다.

(전면 밀착을 원하면 커버를 위아래 두 쪽으로 쪼개는 클램셸이어야 합니다. 조립은
번거로워지지만 캐비티가 카메라 표면을 그대로 따라갈 수 있습니다. 필요하면 말씀해 주세요.)

## "오차 0" 에 대해

FDM 출력에서 공차 0은 만들 수 없습니다. 압출 폭·수축 때문에 구멍은 항상 설계값보다
작게 나오고, 공차 0으로 그리면 아예 안 들어갑니다. 대신 **덜그럭거림 0** 을 목표로
했습니다: 실루엣 + `CLR = 0.30 mm` 오프셋, 그리고 뒷면 나사 2개로 당겨 고정.

공식 메시 154,149 개 점을 캐비티에 넣어 확인한 결과입니다.

```
벽 밖으로 튀어나온 점       0 / 154149
벽까지 최소 여유            0.27 mm
깊이 방향 여유              앞 0.30 mm / 뒤 0.30 mm
벽에 0.45mm 이내로 붙는 점   4.8%   <- 실제로 잡아주는 벨트
```

프린터가 타이트하게 나오면 `CLR` 을 0.20, 헐거우면 0.40 으로 바꿔 다시 생성하세요.

## 순서

### 1단계 — 게이지 출력

`d435_gauge.stl` 은 커버의 **둥근 끝쪽 36 mm** 를 그대로 잘라낸 조각입니다. 끼움이 가장
빡빡한 곳이라 여기서 맞으면 본체도 맞습니다. 카메라 한쪽 끝에 끼워 보고 확인하세요.

1. 끝까지 들어가는가 → 안 들어가면 `CLR` 을 0.40 으로
2. 덜그럭거리는가 → 흔들리면 `CLR` 을 0.20 으로
3. M3 구멍에 나사가 들어가는가 (구멍 위치는 CAD 값이라 안 맞을 이유는 없습니다)

### 2단계 — 커버 출력

- 재질 PETG 또는 ABS 권장. PLA 는 D435 발열과 조명 아래에서 변형될 수 있습니다.
- **뒷판이 베드에 닿는 방향으로 이미 회전돼 있습니다.** 그대로 슬라이싱하세요.
  서포트가 필요 없고, 나사 구멍이 층 방향과 직각이라 가장 튼튼합니다.
- 벽 4겹, 인필 30% 이상.

### 3단계 — 조립

```
카메라 → 커버 앞쪽 개구부로 밀어 넣음 → 뒤에서 M3 2개로 고정
```

**나사 길이 주의.** D435 의 M3 나사산은 **2.5 mm 깊이뿐**입니다. 뒷판 3.0 mm 를 지나
2.0 mm 만 물리도록 **M3 × 5 mm** 를 쓰세요. M3 × 8 이상을 쓰면 바닥을 치면서 카메라
내부 보스를 깹니다.

암 체결용 M3 접시머리 4개는 **카메라를 넣기 전에** 커버 안쪽에서 위로 꽂습니다.
머리가 캐비티 면과 같은 높이로 묻히게 카운터싱크가 파여 있습니다.

### 4단계 — 암 장착 (다른 브래킷이 있으면 건너뜁니다)

`d435_arm.stl` 은 **필수가 아닙니다.** 커버와 그리퍼를 잇는 무언가가 필요할 뿐이고,
그 무언가를 모르기 때문에 가장 확실한 체결점인 툴 플랜지 기준으로 하나 만들어 둔
것입니다. 이미 쓰는 브래킷이 있으면 이 파일은 버리고 커버 윗면의 **M3 4공
(x = ±20 mm, 앞면에서 7 / 21 mm)** 만 인터페이스로 쓰면 됩니다.

베이스 원판은 ISO 9409-1-50-4-M6 (Ø50 플랜지, M6 4개 @ Ø31.5 피치원, Ø6 위치핀)
규격으로, 로봇 툴 플랜지와 Robotiq 커플러 **사이에 끼워** 조입니다.

- 판 두께가 6 mm 이므로 **기존 M6 볼트보다 6 mm 긴 것**이 필요합니다.
- 6 mm 만큼 그리퍼가 툴 축 방향으로 밀려납니다. → **TCP 와 핸드아이 캘리브레이션을
  다시 잡아야 합니다.** 이 저장소의 캘리브레이션 결과는 장착 후 전부 무효입니다.
- 커플러를 분해하기 싫으면 2F-85 몸통 볼트 스펙을 주세요. 몸통 직결 버전으로
  베이스만 바꿔 드립니다.

## 부품표

| 수량 | 규격 | 용도 |
|---|---|---|
| 2 | M3 × 5 소켓 캡, 와셔 포함 | 카메라 → 커버 뒷판 |
| 4 | M3 × 12 접시머리 + M3 너트 | 커버 → 암 |
| 4 | M6 (기존보다 6 mm 긴 것) | 플랜지 샌드위치 |

## 그 밖에

- **시야:** 앞면은 완전히 개방입니다. 립이 없어 87° × 58° 화각을 전혀 가리지 않습니다.
- **USB-C:** 뒷판을 가운데 ±30 mm 만 남겨 양쪽 끝을 열어 두었습니다. 케이블이 뒤로
  빠져나옵니다.
- **삼각대 구멍:** 바닥 Ø11 구멍으로 1/4-20 에 접근할 수 있습니다.

## 주요 파라미터

| 변수 | 기본 | 의미 |
|---|---|---|
| `CLR` | 0.30 | 실루엣 오프셋 = 끼움 공차 |
| `WALL` | 2.4 | 둘레 벽 두께 |
| `REAR_WALL` | 3.0 | 뒷판 두께 |
| `REAR_HALF_X` | 30.0 | 뒷판이 덮는 반폭 |
| `GAUGE_X` | (-48, -12) | 게이지로 잘라낼 구간 |
| `ARM_R` | 42.0 | 툴 축에서 커버 윗면까지 반경 거리 |
| `ARM_Z` | 60.0 | 플랜지면에서 카메라 중심까지 툴축 거리 |
| `FLANGE_T` | 6.0 | 샌드위치 판 두께 |

암의 `ARM_R`, `ARM_Z` 두 값이 그리퍼와의 간섭을 결정합니다.
