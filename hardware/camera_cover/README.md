# RealSense D435 그리퍼 커버 (Robotiq 2F-85 / 2F-140)

`d435_gripper_cover.py` 를 실행하면 STL 3개가 나옵니다.

| 파일 | 용도 | 대략 출력 시간 |
|---|---|---|
| `d435_gauge.stl` | **먼저 이것부터.** 끼움과 M3 구멍 위치만 확인하는 시험 조각 | 20분 |
| `d435_sleeve.stl` | 카메라를 감싸는 커버 본체 | 2시간 |
| `d435_arm.stl` | 툴 플랜지와 그리퍼 커플러 사이에 끼우는 암 | 3시간 |

```bash
python d435_gripper_cover.py            # 이 디렉터리에 STL 생성
python d435_gripper_cover.py /tmp/out   # 다른 데 저장
```

## "오차 0" 에 대해

FDM 출력에서 공차 0은 만들 수 없습니다. 압출 폭·수축·엘리펀트풋 때문에 구멍은 항상
설계값보다 0.1~0.3 mm 작게, 바깥 치수는 크게 나옵니다. 공차 0으로 그리면 카메라가
아예 안 들어갑니다.

대신 **덜그럭거림 0** 을 목표로 설계했습니다.

- 캐비티는 한 면당 `CLR = 0.30 mm` 만 띄웁니다.
- 뒷면 M3 나사 2개가 카메라를 뒷판 쪽으로 당겨 앞뒤 유격을 없앱니다.
- 양끝 벽이 좌우를, 위아래 벽이 상하를 잡습니다.

결과적으로 나사를 조이면 유격이 사라집니다. 프린터가 타이트하게 나오면 `CLR` 을
0.20, 헐거우면 0.40 으로 바꿔 다시 생성하세요.

## 순서

### 1단계 — 게이지부터 출력하고 캘리퍼로 확인

`d435_gauge.stl` 은 커버와 **완전히 같은 단면**에 폭만 줄인 조각입니다. 카메라 뒷면에
대 보고 두 가지를 확인하세요.

1. M3 구멍 2개가 카메라 나사구멍과 맞는가 (설계값: 중심간 **45.0 mm**)
2. 구멍 중심 높이가 맞는가 (설계값: 카메라 바닥면에서 **12.5 mm** = `M3_Z`)

안 맞으면 캘리퍼로 잰 값을 스크립트 상단 `M3_SPACING`, `M3_Z` 에 넣고 다시 생성합니다.
이 두 숫자만 맞으면 나머지는 다 맞습니다.

### 2단계 — 커버 출력

- 재질 PETG 또는 ABS 권장. PLA 는 D435 발열과 조명 아래에서 변형될 수 있습니다.
- **뒷판이 베드에 닿는 방향으로 이미 회전돼 있습니다.** 그대로 슬라이싱하세요.
  서포트가 필요 없고, 나사 구멍이 층 방향과 직각이라 가장 튼튼합니다.
- 벽 4겹, 인필 30% 이상.

### 3단계 — 조립

```
카메라 → 커버 앞쪽 개구부로 밀어 넣음 → 뒤에서 M3 2개로 고정
```

**나사 길이 주의.** D435 의 M3 나사산은 **2.5 mm 깊이뿐**입니다. 뒷판 3.0 mm 를 지나
2.0 mm 만 물리도록 **M3 × 5 mm** 를 쓰세요. M3 × 8 이상을 쓰면 바닥을 치면서 카메라
내부 보스를 깹니다.

암 체결용 M3 접시머리 4개는 **카메라를 넣기 전에** 커버 안쪽에서 위로 꽂습니다.
머리가 캐비티 면과 같은 높이로 묻히게 카운터싱크가 파여 있습니다.

### 4단계 — 암 장착

암의 베이스 원판은 ISO 9409-1-50-4-M6 (Ø50 플랜지, M6 4개 @ Ø31.5 피치원, Ø6 위치핀)
규격입니다. 로봇 툴 플랜지와 Robotiq 커플러 **사이에 끼워** 조입니다.

- 판 두께가 6 mm 이므로 **기존 M6 볼트보다 6 mm 긴 것**이 필요합니다.
- 6 mm 만큼 그리퍼가 툴 축 방향으로 밀려납니다. → **TCP 와 핸드아이 캘리브레이션을
  다시 잡아야 합니다.** 이 저장소의 캘리브레이션 결과는 장착 후 전부 무효입니다.
- 커플러를 분해하기 싫으면 `FLANGE_T` 를 0 에 가깝게 줄이는 대신 그리퍼 몸통에 직접
  체결하는 형태로 베이스를 바꿔야 합니다. 2F-85 몸통 볼트 스펙을 주시면 그 버전을
  만들어 드립니다.

## 부품표

| 수량 | 규격 | 용도 |
|---|---|---|
| 2 | M3 × 5 소켓 캡, 와셔 포함 | 카메라 → 커버 뒷판 |
| 4 | M3 × 12 접시머리 + M3 너트 | 커버 → 암 |
| 4 | M6 (기존보다 6 mm 긴 것) | 플랜지 샌드위치 |

## 설계에서 확정한 값과 가정

**확정 (Intel D400 데이터시트):** 바디 90 × 25 × 25 mm, 뒷면 M3 × 0.5 두 개 중심간
45 mm 깊이 2.5 mm, 바닥 1/4-20 삼각대 구멍.

**가정 (게이지로 확인 필요):**
- M3 구멍 중심 높이 = 바닥에서 12.5 mm (높이 중앙).
- USB-C 커넥터 위치. 확실치 않아서 **뒷판을 가운데 ±30 mm 만 남기고 양쪽 끝과 뒤쪽
  모서리를 열어** 두었습니다. 포트가 뒤쪽 어디에 있든 케이블이 빠져나옵니다.

**시야 간섭:** 앞면은 완전히 개방입니다. 립이 없어 D435 의 87° × 58° 화각을 전혀
가리지 않습니다.

## 주요 파라미터

스크립트 상단에서 바꾸세요.

| 변수 | 기본 | 의미 |
|---|---|---|
| `CLR` | 0.30 | 한 면당 끼움 공차 |
| `M3_Z` | 12.5 | 바닥에서 M3 구멍 중심까지 높이 |
| `M3_SPACING` | 45.0 | M3 구멍 중심간 거리 |
| `ARM_R` | 42.0 | 툴 축에서 커버 윗면까지 반경 거리 |
| `ARM_Z` | 60.0 | 플랜지면에서 카메라 중심까지 툴축 거리 |
| `FLANGE_T` | 6.0 | 샌드위치 판 두께 |

암의 `ARM_R`, `ARM_Z` 두 값이 그리퍼와의 간섭을 결정합니다. 손가락이 화면 아래쪽
가장자리에 걸치게 하려면 `ARM_Z` 를 키우고, 카메라를 툴 축에 붙이려면 `ARM_R` 을
줄이세요.
